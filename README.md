# FitOrDie

> Tu testigo honesto de alimentación y cambio físico. Si venís bien, te motiva.
> Si te pasás o te escondés, te reta. Sin humo en ninguna dirección.

## Qué es

Webapp mobile-first (PWA instalable en iPhone + web desktop) para:

- Registrar qué comés, cuánto y a qué hora (diario alimentario).
- Calcular calorías, proteínas, grasas, carbos y carbos netos.
- Evaluar compatibilidad keto orientativa de cada comida.
- Seguir peso, medidas y evolución (privado por defecto).
- Recetario con filtros reales por ingredientes y atributos.
- Integrarse con un bot de Telegram (API autenticada, idempotente).

Una sola voz: motiva cuando cumplís, reta cuando te mentís. Crudeza configurable.

## Stack (propuesto)

Next.js + React + TypeScript · Tailwind · PostgreSQL · Docker Compose · PWA.
